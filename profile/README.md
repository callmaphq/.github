# Callmap

Callmap is a call graph reader for an engineer who still reads code. Each language has its own distribution.

- **TypeScript:** [callmap-ts](https://github.com/callmaphq/callmap-ts). Run `npm install --global callmap-ts`.
- **Go:** [callmap-go](https://github.com/callmaphq/callmap-go). Run `go install github.com/callmaphq/callmap-go@latest`.
- **Ruby:** [callmap-rb](https://github.com/callmaphq/callmap-rb). Run `gem install callmap-rb`.

[callmap-core](https://github.com/callmaphq/callmap-core) holds the reader page, the review core and the conformance suite. Until the distributions ship, run `npm install --global @callmap/cli`.
